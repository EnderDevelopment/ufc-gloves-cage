# Minecraft Texture Pack: Guantes y Rejas UFC

Guantes y Rejas UFC es un conjunto de Minecraft texture assets que incluye una textura de accesorio o armadura para el pecho con guantes negros de UFC y una block texture para rejas de jaula UFC en estilo pixel art 3D, preparada como base para un resource pack de Minecraft.

## Install

1. Descarga o copia las texturas del proyecto.
2. Convierte los archivos SVG a PNG conservando sus dimensiones:
   - `ufc_gloves.svg` debe conservar una proporción de 64 × 32 píxeles.
   - `ufc_cage_block.svg` debe conservar una proporción de 32 × 32 píxeles.
3. Crea o abre un resource pack de Minecraft compatible con tu versión.
4. Coloca cada PNG en la ruta de textura correspondiente dentro de `assets/minecraft/textures/`.
5. Si quieres usar los guantes como accesorio equipable, asígnales el modelo, el ítem o la armadura de pecho mediante la configuración de tu resource pack o de tu mod.
6. Coloca la textura de rejas en la ruta del bloque que quieras reemplazar o configura un modelo de bloque para utilizarla.
7. Activa el resource pack desde las opciones de Minecraft.

## Use

- Usa `ufc_gloves.svg` como textura de una pieza de armadura de pecho o accesorio visual. La textura representa el torso y dos guantes negros extendidos hacia las manos.
- Usa `ufc_cage_block.svg` como textura para un bloque de rejas de jaula. El diseño incluye barras oscuras, uniones con forma de diamante y sombreado con perspectiva 3D.
- Ajusta los modelos JSON y las rutas de textura según la versión de Minecraft y el sistema de mods o resource pack que utilices.
- Los archivos SVG son fuentes de textura editables. Minecraft normalmente requiere PNG para mostrar texturas dentro de un resource pack.
